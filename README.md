# Customer-Churn-Analysis

Project Overview

This project focuses on analyzing customer churn to understand why customers leave a service and identify key factors influencing churn. The analysis helps businesses improve customer retention by making data-driven decisions.

Objectives

Analyze customer behavior and churn patterns

Identify important features contributing to churn

Build a churn prediction model

Visualize insights from exploratory data analysis (EDA)

Tools & Technologies

Python

Pandas, NumPy

Matplotlib, Seaborn

Scikit-learn

Jupyter Notebook

GitHub

Key Steps Performed

Data cleaning and preprocessing

Exploratory Data Analysis (EDA)

Feature encoding and scaling

Model building for churn prediction

Model evaluation using accuracy and other metrics

Key Insights

Customers with month-to-month contracts show higher churn

Higher monthly charges are associated with increased churn

Longer customer tenure reduces churn probability
